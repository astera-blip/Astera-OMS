# 商品建立 SOP

## Purpose

Create products and variants without hardcoding artist, company, CP, brand, or series relationships.

## Draft Steps

1. Confirm official product source.
2. Create or select related company, artist, CP group, brand, and series.
3. Create Product.
4. Create at least one Product Variant.
5. If the product has no visible options, create Default Variant.
6. Create Sale Campaign with sale period and rules.
7. Upload public images.
8. Review public product data before publish.
9. Publish only after price, closing date, and payment notes are confirmed.

## Checks

- Product cost is private.
- Internal notes are private.
- Public page does not expose private fields.
- Historical product changes will not modify existing order item snapshots.
