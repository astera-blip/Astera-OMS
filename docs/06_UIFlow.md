# UI Flow Draft

This file records early UX flow direction. Visual design is not finalized.

## Public Storefront

### Home

- Show current sale highlights.
- Show clickable product carousel or featured product section.
- Show LINE community entry clearly.
- Show latest announcements.
- Show footer links for brand, social, FAQ, terms, and privacy.

### Product Browsing

Desktop navigation should support:

- All products
- Company
- Artist
- CP group
- Brand or series

Mobile navigation should use a compact menu and remain fully usable.

### Product Detail

Display:

- Product images
- Product name
- Public description
- Variants
- Sale campaign status
- Price
- Closing date
- Public preorder, supplement, and shipping notes
- Add-to-cart action

Internal cost, private notes, purchase status, and profit information must not appear in the public page payload.

## Member Area

- Google login.
- First-login profile completion.
- Cart.
- Checkout.
- Own order list.
- Own order detail.
- Own payment requests and basic payment status.

## Admin Workspace

The admin landing page should be a work center, not only a dashboard.

Initial work queues:

- Pending payment confirmation
- Pending product setup
- Pending order review
- Duplicate phone warnings
- Cancellation requests
- High-risk member notes

## Deferred Visual Decisions

- Final brand name.
- Logo.
- Colors.
- Typography.
- Exact homepage layout.
- Whether public stock count is shown.
