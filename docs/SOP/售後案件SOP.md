# 售後案件 SOP

## Purpose

Track exceptions as Cases instead of private memory or scattered notes.

## Draft Steps

1. Create Case with type.
2. Link Case to member, order, order item, payment, arrival item, or shipment as relevant.
3. Record evidence and communication.
4. Assign owner or helper.
5. Update status until resolved or closed.
6. Record outcome and financial impact if any.

## Checks

- Private customer evidence must not be public.
- Case events should form a timeline.
- Financial corrections use adjustments or ledger entries.
