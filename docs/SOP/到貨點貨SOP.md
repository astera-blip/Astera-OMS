# 到貨點貨 SOP

## Purpose

Track arrival batches and item-level status for later supplement payment and shipment.

## Draft Steps

1. Create Arrival Batch for received package.
2. Match received items to Purchase Items and Order Items.
3. Mark quantity and condition.
4. Record missing, damaged, or wrong items.
5. Create Case for exceptions.
6. Prepare supplement calculation when applicable.

## Checks

- Arrival photos or videos are private unless intentionally published.
- Exceptions should be Cases, not only free-text notes.
