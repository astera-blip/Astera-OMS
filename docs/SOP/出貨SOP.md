# 出貨 SOP

## Purpose

Prepare shipment only after required payment and supplement conditions are satisfied.

## Draft Steps

1. Confirm order item is ready to ship.
2. Confirm required payments are complete or formally deferred.
3. Confirm recipient information.
4. Create Shipment.
5. Export shipping data when template is available.
6. Record tracking or platform shipment state.
7. Mark shipped order items.

## Checks

- Shipping export files contain personal data and must be private.
- Export action should be logged.
